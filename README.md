# 🚀 CreatorFlow AI

> **One Source. Infinite Possibilities.**

CreatorFlow AI is a multilingual Generative AI platform designed to transform a single source of content into multiple useful outputs.

Users can upload documents, presentations, images, and videos or simply chat with AI using natural language. CreatorFlow AI understands the user's language, including multilingual and mixed-language conversations, and helps create educational and creator-focused content.

---

## ✨ Key Features

### 🤖 Multilingual AI Chat

CreatorFlow AI supports natural conversations across multiple languages.

- English
- Tamil
- Tanglish
- Hindi
- Telugu
- Malayalam
- Kannada
- Bengali
- Marathi
- Gujarati
- Punjabi
- Urdu
- Spanish
- French
- German
- Portuguese
- Japanese
- Korean
- Chinese
- Arabic
- Other languages supported by the configured AI model

### 🌐 Automatic Language Detection

Users don't need to select a language before chatting.

CreatorFlow AI automatically understands:

- Different languages
- Mixed-language messages
- Transliteration
- Tanglish-style conversations
- Language switching during a conversation
